# ✧ Kingshima Platform

A modern, faith-driven tech innovation and learning platform equipping students with technical skills, creative tools, and practical project mastery.

---

## 🌟 Features

- **🤖 AI Agent Assistant**: Instant Q&A helper, bootcamp course finder, and clean code structure optimizer (accessible via `Ctrl + K`).
- **🔴 Red Box Cursor Inspector**: Animated red cursor box tracking text, words, etymologies/origins, and images with directional code structure suggestions.
- **⚡ Custom Node.js Backend**: Lightweight, zero-external-dependency Node.js backend with persistent atomic data storage, PBKDF2 password hashing, and HMAC-SHA256 JWT authentication.
- **🎓 Bootcamp Dashboard**: Course catalog, week-by-week curriculum, interactive playgrounds (Code, Data, PromptLab), assignment submissions, and progress tracking.

---

## 🛠️ Technology Stack

- **Frontend**: Next.js 16 (App Router), React 19, CSS Modules, Framer Motion, Lucide Icons.
- **Backend**: Node.js, Express REST API, persistent file database engine (`server/data/db.json`), PBKDF2 cryptography, JWT auth.
- **Payment Gateway**: Paystack integration.

---

## 🚀 Getting Started

### 1. Environment Configuration
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

### 2. Run Next.js Development Server
```bash
npm run dev
```

### 3. Run Standalone Node.js Backend Server (Optional)
```bash
npm run server
```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.
